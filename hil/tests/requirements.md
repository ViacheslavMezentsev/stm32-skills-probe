# Требования к зонду (HIL)

Каждый сценарий начинается со сброса. Плату выбирает сборка (пресеты `*-hil`) через конфигурацию прогона
`hil/sessions/<плата>.toml`: описание MCU (`hil/profiles`), параметры сценариев (`hil/api.toml`) и файл
данных платы (`hil/boards`). Остановки GDB замораживают SysTick вместе с ядром; сценарии проверяют
логику и раскладку зонда, а не реальное время и не метрологию.

## HW_BOOT
Зонд достигает `probe_loop()` без отказа: `platform_fault` и `probe_fault_vector` равны 0, `probe_state`
равен 0xA5. `SystemCoreClock` равен частоте HSE или HSI из файла данных платы; бит 0 флагов телеметрии
выставлен тогда и только тогда, когда ядро работает от HSE без отказа запуска.

## HW_BOARD_PROFILE
Описание MCU, файл данных платы и сборка относятся к одной плате: имя платы входит в название MCU, сборка
определяет макрос устройства из файла данных, файл данных захвачен прогоном. DEV_ID совпадает с описанием.
Начальный указатель стека равен концу SRAM платы, вектор сброса — Thumb-код во Flash описания. Регистр данных
USART1 не читается как память (`outside_window`). Профиль сохраняется в записях результата.

## HW_FRAMES
Два соседних входа в `probe_emit_frame()` дают номера кадров N и N+1, а разница `tick` равна периоду кадров
из `api.toml` с допуском в один тик.

## HW_SAMPLE_HOOK
Указатель `probe_sample_hook` в RAM указывает на `probe_sample()`; два соседних вызова увеличивают счётчик
`samples` на один (по модулю 65536); функция возвращается в вызывающий код.

## HW_COMPUTE_RETURN
`probe_compute()` возвращает xorshift своего аргумента (значение проверяется по возврату через `finish`).

## HW_WORK
Участок известной длины выполняет число итераций из `api.toml`; число тактов DWT, которое возвращает
`probe_work()`, не меньше числа итераций и не больше двадцатикратного, и совпадает с `work_cycles` телеметрии.

## HW_RTT_BLOCK
Управляющий блок `_SEGGER_RTT` содержит строку `SEGGER RTT`, один канал вверх и один вниз с размерами из
`api.toml`; буфер канала вверх находится в SRAM платы, и стартовый лог уже записан в него.
